## 4. ระดับความสำคัญ

**คำถามจัดระดับ (ถามตามลำดับ ตอบ "ใช่" ข้อแรกแล้วหยุด):**

1. ถ้าพัง ลูกค้าได้ **ผลวิเคราะห์/ตัวเลขผิด** หรือ **สิทธิ์ผิด / ข้อมูลส่วนตัวรั่ว / ข้อมูลชนกัน** ใช่ไหม? → **P1**
2. ถ้าพัง ลูกค้าหรือเจ้าหน้าที่ **ใช้ฟีเจอร์นั้นไม่ได้หรือได้ผลผิดในฟีเจอร์รอง** แต่ยังแก้ค่า/ลองใหม่/ใช้ทางอื่นได้ ใช่ไหม? → **P2**
3. นอกนั้น (การแสดงผล ข้อความ ความสะดวก) → **P3**

| ระดับ | ฟีเจอร์ (ตาม EXPLORATION ส่วน E) |
| --- | --- |
| P1 | สิทธิ์หลังบ้าน (Self-approve, RBAC, Session/Logout) · Publish/Rollback ซ้อน · Privacy · Lockout + Rate limit Login · คู่เลข 6 คู่ + ระดับ · ผลรวมทะเบียน 2 แบบ + ค่าอักษร |
| P2 | Validation เบอร์/ทะเบียน · คำแนะนำอาชีพ/เป้าหมาย · วันเกิด Highlight · Rate limit วิเคราะห์ · หมวด/Audit/ความยาวข้อความหลังบ้าน · จอมือถือ |
| P3 | ข้อความ Error ที่ไม่ตรงช่อง · การแสดงทะเบียน · ค้นคู่ว่าง/หมวดบทความไม่มีจริง · บทความ/404 |
