## 1. คำขอเริ่มต้น
ผู้ใช้ขอพรอมต์ภาษาไทย (ไม่เกิน 150 บรรทัด แบ่งขั้นมีเลขกำกับ) สำหรับให้ Claude หน้าต่างใหม่สร้างเว็บ **"สบายใจ สปา · Sabai Jai Wellness Spa"**
โดยพรอมต์ต้องอ้างอิง REQUIREMENTS.md, DESIGN.md และ TEST-DATA.md และสั่งงาน 11 ข้อ:
- Stack: Next.js + PostgreSQL 16 (`pg`, ไม่ใช้ ORM)
- Docker 2 โปรเจกต์ (db / web)
- ใช้บน Windows ได้
- รูปภาพจาก Codex หรือ SVG
- ดีไซน์
- ฟีเจอร์ครบตาม FR/BR
- "AI" เป็นกฎตายตัว
- data-testid และ test reset
- BUG_MODE
- SPEC.md
- ตรวจส่งมอบ

## 2. สิ่งที่พบ
- ใน repo ไม่มีไฟล์ชื่อ REQUIREMENTS.md / DESIGN.md
- เอกสารที่มีอยู่จริง (`requirement/system-requirements.md`, `design/*.md`, `test-data/test-data.md`) เป็นของ **"ระบบเลขมงคลและทะเบียนรถมงคล"** ไม่ใช่สปา
- ค้นทั้งโฟลเดอร์ `track-4-ai-vibe-codeing` แล้วไม่พบเอกสารสปา
- เสนอ 3 ทางเลือก ผู้ใช้เลือก **ข้อ 2: ปรับพรอมต์ให้ตรงกับเอกสารเลขมงคล**
